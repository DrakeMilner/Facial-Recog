# Facial Recognition - IT 254-002
Project Details

Trained Recog Model:

⦁	Teachable Machine

⦁	Model was trained to recognize each of the group members faces and possibly the emotion they might have been showing while looking at the camera

⦁	Exported into a Keras Version for easy interconnection with python and Arduino

Build Arduino:

⦁	used a basic build for a Liquid Crystal Display from the Arduino IDE tools provided.

⦁	https://docs.arduino.cc/learn/electronics/lcd-displays/

⦁	Easy to understand explanation of how to build LCD breadboard to Arduino. ^

Code Arduino IDE:

⦁	Uploaded Arduino code above to the IDE and verify + upload to to Arduino.

Python Code:

⦁	Upload python code to 3.11.0 using Visual Studio code, will not work as well with another port or version.

⦁	Will need to do multiple pip installs. (listed in materials)

Test System:

⦁	Verify through Arduino and upload to mega.

⦁	run code on visual studios.

⦁	if working, camera should show up and lcd should reflect the face/emotion being shown.




Materials:

⦁	Python 3.11.0

⦁	TensorFlow(pip)

⦁	Keras Export Version(pip)

⦁	Open CV(pip)

⦁	PySerial(pip)

⦁	Arduino IDE
⦁	Arduino Mega 2560
⦁	Visual Studio Code
